System design

How it all fits together

One EC2 instance hosts Jenkins, the Docker engine and a single-node k3s Kubernetes cluster. Docker Hub stores the images in between.

Components

ComponentRolePort / location
Jenkins LTSPipeline orchestrator (declarative Jenkinsfile)EC2 :8080
Docker EngineBuilds and pushes container images/var/run/docker.sock
Docker HubStores versioned images<user>/shipyard
k3sLightweight, CNCF-certified KubernetesAPI :6443 (local)
Deployment3 replicas, rolling update, probes, resource limitsnamespace shipyard
ServiceLoad-balances traffic across podsNodePort :30080
🔐

Security

Container runs as a non-root user; registry credentials live in the Jenkins credential store; the security group exposes only SSH, Jenkins and the app port.

🩺

Self-healing

Liveness and readiness probes on /healthz and /readyz let Kubernetes restart unhealthy pods and hold traffic until pods are ready.

📈

Scalable

Scale with kubectl scale deploy/shipyard --replicas=5 — the Service picks up new pods automatically.
