DevOps Project · CI/CD

From git push to a live Kubernetes deployment — automatically.

Shipyard is a Dockerized Node.js application delivered by a Jenkins pipeline: every commit is tested, packaged into an image, pushed to Docker Hub and rolled out to a Kubernetes cluster on AWS with zero downtime.

What this project demonstrates

      
A complete, reproducible delivery workflow built with industry-standard tools.

    

    

      
⚙️
Continuous Integration
Jenkins checks out the repository on every push, installs dependencies and runs the automated test suite before anything is built.

      
🐳
Containerization
A multi-stage Dockerfile produces a small, non-root production image tagged with the Jenkins build number and commit SHA.

      
📦
Image Registry
Images are pushed to Docker Hub using Jenkins-managed credentials, so secrets never live in the repository.

      
☸️
Kubernetes Deployment
The pipeline applies manifests and performs a rolling update across three replicas with readiness and liveness probes.

      
✅
Automated Verification
Jenkins waits for the rollout to complete and smoke-tests the live service. A failed rollout is rolled back automatically.

      
☁️
Runs on AWS
Jenkins, Docker and a lightweight k3s Kubernetes cluster run on an Amazon EC2 instance, provisioned by a single bootstrap script.
