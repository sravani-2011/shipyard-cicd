    Release strategy

    How a new version reaches users without downtime.

    🏷️

    Immutable tags

    Every image is tagged <build>-<sha> as well as latest, so any release can be traced back to its commit.

    🔁

    Rolling updates

    maxUnavailable: 0 and maxSurge: 1 keep all three replicas serving while new pods come up.

    ↩️

    Automatic rollback

    If kubectl rollout status times out, the pipeline runs kubectl rollout undo and marks the build failed.
